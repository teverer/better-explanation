# Better Explanation / 更好的 AI 讲解

> 把教学材料改写成一份面向单个学习者、真正帮助理解的教学文档，而不是又一份“读起来很顺、合上就忘”的 AI 输出。

**Status:** v0.1 · experimental prompt · 2026-11

## 这是什么

Better Explanation 是一个提示词，不是应用。它让模型先读你提供的教学材料，再产出一份“概念理解教学文档”：

- 先减外在负荷，再讲解；
- 一次只讲一个概念；
- 功能/作用是必要的，机制按学习目标决定是否展开；
- 只讲理解当前概念必需的前置/对比关系；
- 每个概念后都有复述、预测、反例或迁移检查；
- 材料没有的，明确标“材料未说明”，不补编。

它不是题库、不是考试系统、不是技能训练平台。

## 它解决什么问题

直接问 AI 时，回答往往“太顺、太全、太通用”，造成：

- 一次涌入太多新概念，超过工作记忆；
- 寒暄、重复、装饰性内容占用认知资源；
- 不知道读者已会/未会什么，对新手跳步、对专家啰嗦；
- 缺少分段、信号、因果链；
- 读起来很顺，导致“以为懂了”的流畅性错觉。

## 怎么用

1. 打开 [`prompts/v0.1.md`](prompts/v0.1.md)。
2. 整段复制到一个新的对话。
3. 附上教学材料：讲义、笔记、notebook、文档、代码、论文。
4. 如果有学习者画像/学习目标，也一起附上。
5. 让模型先完整阅读材料，再产出教学文档。

> 只给一个概念名词的输入方式，计划在后续版本支持；v0.1 以“有材料”为主。

## 设计原则

1. **减少外在负荷**：连贯、信号、冗余、空间邻近、时间邻近（Mayer 五条）。
2. **一次一个概念**：新概念先给指称/例子，再给名字。
3. **功能必要，机制按目标触发**：不固定顺序，不硬塞机制。
4. **关系只讲必要的**：前置、对比、包含；说明“为什么需要知道”。
5. **讲完必须检查**：复述、预测、反例、迁移；不打分。
6. **不编造**：材料没有就标“材料未说明”。
